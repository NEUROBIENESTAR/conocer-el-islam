# Conociendo el Islam

Espiritualidad y vida cotidiana — un espacio claro, humano y respetuoso para conocer el islam desde cero.

Sitio educativo que presenta el islam desde una mirada integral: espiritualidad, historia, psicología y neurociencia (esta última usada para comprender procesos humanos, nunca para "demostrar" la fe). Pensado para personas sin conocimiento previo, musulmanas o no, que quieran aprender a su propio ritmo.

## Estructura del sitio

```
/index.html          → página principal
/registro.html        → alta de nuevos usuarios (conectado a Google Apps Script)
/programa.html         → contenido completo del programa (pendiente)
/login.html            → acceso de usuarios existentes (pendiente)
/modulos/               → módulos del curso
/rutas/                 → páginas de cada ruta de aprendizaje
/assets/                → imágenes, íconos y recursos
```

## Estado del proyecto

En construcción. El `index.html` y `registro.html` ya están listos; el resto del contenido se agrega módulo por módulo.

## Tecnología

Sitio estático (HTML, CSS y JavaScript sin frameworks), desplegado con Cloudflare Pages. El registro usa Google Apps Script como receptor temporal de datos, sin sistema de cuentas todavía.
